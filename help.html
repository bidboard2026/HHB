HOW POINTS WORK

Sending a real message (10+ characters)+5 pts
Staying in a room+1 pt / minute

CHAT COMMANDS

/whisper nickname message (or /w)Send a private line only you and that person can see, right in the main room
/face :100Set an emoji as your avatar (see the emoji code list below). /face clear resets it
:100 anywhere in a messageRenders as the matching emoji — try :100 through :199

The commands below need specific role tags (see ROLES & PERMISSIONS):

/clearWipe all messages in the current room
/topic new topic textChange the room's topic
/gift nickname amountAward points to someone
/tag nickname tagnameToggle a tag on/off for someone
/tempadmin nickname minutesGrant temporary admin that expires automatically
/invisible on|offHide yourself from the online users list
/mute nickname, /unmute nicknameMute or unmute someone
/kick nicknameForce someone to log in again
/ban nicknameBan someone from the current room

ROLES & PERMISSIONS

Every tag shows as a badge next to a person's name. Permissions are the union of all tags someone holds.

👑 OwnerEverything: ban, kick, mute, change topic, go invisible, gift points, change others' tags, grant temp admin, change levels, clear chat
⭐ Super AdminSame as Owner
🛡️ AdminBan, kick, mute, clear chat
♚ King / ♛ QueenBan, kick, mute
🎙️ RJ HeadMute
⭐ VIP / 💎 Platinum / 🥇 Gold / 🥈 Silver / 🛡️ ImmuneCosmetic badges — no special permissions

Roles/tags are assigned via the admin control panel's Create User page, or in-room using /tag nickname tagname (needs the changeTags permission).

PRIVATE MESSAGES & CALLS

How do I send someone a PM?
Click their name in the People list, or open Private Messages and type a username to start a new thread.

Can I send photos in a PM?
Yes — use the 📎 button in a conversation to attach an image.

Where do emojis come from?
Click the 😊 button just above the message box, in either the chat room or a PM — it opens Static and Animated tabs.

What happens if someone @mentions me?
Their message is highlighted and a banner appears at the top of the room so you don't miss it.

Can I call someone?
Audio/video call buttons are available in the chat room and in each PM conversation. This is currently a UI preview — full real-time audio/video requires a signaling server, which isn't wired up yet.

FAQ

How do I change my avatar?
Go to Profile and paste an image URL or a YouTube link.

How do I block private messages?
Go to Settings → Privacy and choose "Block All PMs."

How do I stop the chat from auto-scrolling?
Go to Settings → Chat Window and choose "Freeze scroll position."

How do I like or dislike someone?
Open the Most Loved page and send a reaction to their username.

How do I hide the People list?
Click the ⏴ icon at the bottom of the sidebar in the chat room to collapse or expand it.
